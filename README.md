# Amazon Clone

A responsive front-end recreation of the Amazon shopping homepage built using **HTML and CSS**. This project focuses on recreating the visual structure of an e-commerce website, including the navigation bar, search section, hero banner, product-category cards, and footer.

## Features

- Amazon-inspired navigation bar
- Location and account sections
- Search bar with category selector
- Navigation menu with shopping options
- Hero banner section
- Product/category cards for:
  - Health & Personal Care
  - Electronics Essentials
  - Home Decor
  - Furniture
  - Pet Care
  - Clothes
  - Beauty Products
  - Grocery Items
- Responsive product grid using CSS Flexbox
- Amazon-inspired footer with multiple sections
- Hover effects for navigation items, buttons, and links
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- CSS Flexbox
